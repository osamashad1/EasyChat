# Website Brief

Edit this file and push. The pipeline sends it to Claude, which writes the
whole website, then the pipeline checks it and deploys it to GitHub Pages.

## Name
EasyChat

## What it is
A simple, friendly chat app that lets small teams talk without the clutter.

## Audience
Small business owners and freelancers who want an easy alternative to big chat tools.

## Pages
- Home: hero, three key features, short testimonial, call to action
- Features: detailed feature list with icons
- Pricing: Free, Pro ($5/user/month), Business ($12/user/month)
- Contact: simple contact form (no backend; use a mailto: link)

## Style
Clean and modern, lots of white space, rounded corners, a calm blue accent.
Must look good on phones. Support dark mode.

## 3D and motion
- Home hero: a real-time 3D scene of glossy chat bubbles floating in a soft particle
  network, with gentle mouse parallax and animated "typing" dots
- Headline that animates in word by word
- An animated chat demo where messages appear with a typing indicator
- Scroll-reveal sections, animated counters, SVG icons that draw themselves,
  a scrolling logo strip and 3D tilt on cards
- Keep motion calm, and turn it off for visitors who prefer reduced motion

## Must have
- Plain HTML, CSS and vanilla JavaScript only (no build step); three.js for 3D
- A shared navigation bar on every page
- Accessible: semantic HTML, alt text, good color contrast
